FAQ

Questions, answered

Where are my publications stored?

In your browser's private storage (IndexedDB) on this device. Nothing is uploaded while you edit. Use Settings → Backup to move work between computers.

How do I share a flipbook publicly?

Editor → Publish → “Export website”. You get one self-contained HTML file with pages, media and the reader. Upload it to your website, Netlify Drop, GitHub Pages, S3 or any static host, then share the link or use the embed code. You can also bundle several publications into a searchable bookshelf site.

How does the AI writer work?

Add your own Anthropic API key in Settings. The studio sends your prompt directly from your browser to Claude, which writes the publication with chapters, quizzes, charts and calls to action. FlipForge then lays it out with your chosen theme. You pay Anthropic only for what you generate.

Where do analytics and leads go?

Readers in the studio's own viewer are tracked on this device. Exported sites store stats in each reader's browser and, if you add a webhook URL or a Google Analytics 4 ID, send sessions, leads and orders to your tools (Zapier, Make, HubSpot, Sheets…).

Is password protection secure?

It stops casual access, but an exported file contains its pages, so for confidential documents host the file behind your own login or server-side protection.

Which files can I import?

PDF (single or batch), JPG / PNG / WebP images, CSV product lists, Markdown, plain text and HTML documents, plus FlipForge project backups.
